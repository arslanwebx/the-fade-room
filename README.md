# The Fade Room VIP Barber Studio

Static single-page website prepared for GitHub and Vercel deployment.

## Deploy on Vercel

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In Vercel, click **Add New > Project**.
4. Import the GitHub repository.
5. Leave Framework Preset as **Other** (or let Vercel auto-detect the static site).
6. Click **Deploy**.

No build command, environment variables, or dependencies are required.

## Files

- `index.html` — complete website with embedded CSS and JavaScript
- `vercel.json` — simple Vercel configuration
- `.gitignore` — ignores common local/editor files
